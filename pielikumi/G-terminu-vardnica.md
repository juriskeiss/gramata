# G pielikums. Terminu vārdnīca

Termini alfabēta secībā ar angļu atbilsmi. Iekavās — nodaļa, kurā termins
skaidrots plašāk.

| Termins | Angliski | Skaidrojums |
| --- | --- | --- |
| AGC | Automatic gain control | Automātiskā pastiprinājuma regulēšana uztvērējā (11.) |
| Amplitūdas modulācija (AM) | Amplitude modulation | Informācija maina nesēja amplitūdu (8.) |
| Antenu skaņotājs | Antenna tuner, ATU | Ierīce, kas saskaņo antenas pretestību ar raidītāju (13.) |
| Apliecība | Certificate | Dokuments par nokārtotu eksāmenu; raidīt vēl neļauj (2.) |
| Atkārtotājs | Repeater | Neapkalpojama stacija, kas signālu uztver un tūlīt raida citā frekvencē (5.) |
| Atļauja | Licence | Tiesības lietot radiostaciju ar konkrētu izsaukuma signālu (2., 3.) |
| Baluns | Balun | Savieno simetrisku antenu ar nesimetrisku kabeli (13.) |
| Blakusizstarojums | Spurious emission | Nevēlams izstarojums ārpus vajadzīgās joslas (4., 12.) |
| CW | Continuous wave | Telegrāfs ar Morzes kodu (8.) |
| Ciparu darba veidi (MGM) | Digital modes | FT8, RTTY, PSK31 u.c.; signālu raida un atšifrē dators (1., 4.) |
| Decibels (dB) | Decibel | Divu jaudu vai spriegumu attiecības logaritmiska mērvienība (8.) |
| Detektors | Detector | Bloks, kas atdala informāciju no nesēja (11.) |
| Diapazons | Band | Radioamatieriem iedalīts frekvenču apgabals, piemēram, 80 m (4.) |
| Dipols | Dipole | Antena no diviem vienāda garuma pleciem, kopā λ/2 (13.) |
| Diskriminators | Discriminator | FM detektors (11.) |
| DX | DX | Tāla stacija vai tāls sakars (5.) |
| Efektīvā vērtība | RMS value | Maiņsprieguma vērtība, kas dod tādu pašu jaudu kā līdzspriegums (7.) |
| Elektromagnētiskā saderība (EMS) | EMC | Iekārtu spēja darboties blakus, savstarpēji netraucējot (16.) |
| Ferīta gredzens | Ferrite toroid, ferrite ring | Gredzenveida ferīta serde. Uz tā tin balunus, ununus un droseles; caur gredzenu vairākas reizes izvērts kabelis slāpē traucējumus, jo gredzens aiztur strāvas pa vada ārpusi. Tam pašam nolūkam lieto arī citu formu ferītus: uz kabeļa uzspiežamas uzmavas un stieņus (13., 16.) |
| Ferīts | Ferrite | Magnētisks materiāls, no kura izgatavo dažādu formu serdes augstfrekvences spolēm, transformatoriem un droselēm. Sarunvalodā par ferītu sauc arī ferīta gredzenu vai gatavu droseli (13., 16.) |
| Fīders | Feeder | Līnija, kas pārvada signālu starp staciju un antenu (3., 13.) |
| Frekvences modulācija (FM) | Frequency modulation | Informācija maina nesēja frekvenci (8.) |
| Galotnes jauda (pX) | Peak envelope power, PEP | Raidītāja jauda signāla maksimumos (4.) |
| Harmonika | Harmonic | Signāls pamatfrekvences daudzkārtnī (8., 12.) |
| Heterodīns | Local oscillator | Uztvērēja ģenerators, ar kuru to noskaņo (11.) |
| Izotropā antena | Isotropic antenna | Teorētiska antena, kas izstaro vienādi visos virzienos; 0 dBi (13.) |
| Izsaukuma signāls | Call sign | Stacijas unikālais vārds ēterā (1., 4.) |
| Izstarojuma klase | Emission class | Trīs zīmju apzīmējums darba veidam, piemēram, A1A — CW, J3E — SSB, F3E — FM (8.) |
| Jaucējs | Mixer | Bloks, kura izejā ir ieejas frekvenču summa un starpība (10., 11.) |
| Joslu plāns | Band plan | Diapazona sadalījums pa darba veidiem (6.) |
| Jutība | Sensitivity | Vājākais signāls, ko uztvērējs vēl uztver (11.) |
| Kapacitāte | Capacitance | Kondensatora spēja uzkrāt lādiņu; mērvienība F (9.) |
| Koaksiālais kabelis | Coaxial cable | Nesimetriska pārvades līnija ar centrālo vadu un ekrānu (13.) |
| Lokators | Locator | Maidenhead burtu un ciparu kods vietai uz kartes: lauks, kvadrāts, apakškvadrāts, piemēram, KO26bw (5.) |
| LSB, USB | Lower / upper sideband | Apakšējā un augšējā sānjosla (6., 8.) |
| Mirusī zona | Skip zone | Apgabals, kuru nesasniedz ne zemes, ne telpas vilnis (14.) |
| Modulācija | Modulation | Informācijas uzlikšana nesējam (8.) |
| Nesējs | Carrier | Augstfrekvences signāls, kas nes informāciju (8.) |
| NVIS | Near vertical incidence skywave | Gandrīz vertikāls telpas vilnis reģionāliem sakariem (14.) |
| Oma likums | Ohm's law | U = I · R (7.) |
| Pārvades līnija | Transmission line | Kabelis vai vadu pāris, kas pārvada signālu (13.) |
| Periods | Period | Viena svārstību cikla ilgums; T = 1 / f (8.) |
| Pile-up | Pile-up | Situācija, kad vienu staciju sauc daudzi (5., 6.) |
| Polarizācija | Polarization | Elektriskā lauka virziens radiovilnī (8.) |
| QSL kartīte | QSL card | Rakstisks sakara apstiprinājums (5.) |
| QSO | QSO | Radiosakars starp divām stacijām (1., 5.) |
| Radiobāka | Beacon | Pastāvīgi raidoša stacija izplatīšanās novērošanai (3., 6.) |
| Raksturpretestība | Characteristic impedance | Pārvades līnijas pretestība, piemēram, 50 Ω (13.) |
| Reaktīvā pretestība | Reactance | Kondensatora vai spoles pretestība maiņstrāvai (9.) |
| Rezonanse | Resonance | Stāvoklis, kurā X_L = X_C (10.) |
| RST | RST | Signāla ziņojums: saprotamība, stiprums, tonis (5.) |
| S metrs | S meter | Signāla stipruma mērītājs uztvērējā (5., 11.) |
| SDR | Software defined radio | Radio, kurā signālu apstrādā programma (11.) |
| Selektivitāte | Selectivity | Spēja atdalīt vajadzīgo signālu no blakus esošajiem (11.) |
| Slodzes ekvivalents | Dummy load | 50 Ω rezistors, kas aizstāj antenu un neizstaro (15.) |
| Split | Split | Raidīšana un uztveršana dažādās frekvencēs (5.) |
| Spoguļkanāls | Image frequency | Otra frekvence, kas superheterodīnā nonāk starpfrekvencē (11.) |
| SSB | Single sideband | Vienas sānjoslas modulācija bez nesēja (8.) |
| Starpfrekvence | Intermediate frequency, IF | Nemainīga frekvence superheterodīnā (11.) |
| Superheterodīns | Superheterodyne | Uztvērējs, kas signālu pārnes uz starpfrekvenci (11.) |
| SWR | Standing wave ratio | Stāvviļņu koeficients; rāda saskaņošanas kvalitāti (13., 15.) |
| Telpas vilnis | Sky wave | Vilnis, kas atstarojas no jonosfēras (14.) |
| Transīvers | Transceiver | Raidītājs un uztvērējs vienā korpusā (1.) |
| UTC | Coordinated universal time | Koordinētais universālais laiks; to lieto žurnālā (5.) |
| Viļņa garums | Wavelength | Attālums, ko vilnis noiet viena perioda laikā; λ = 300 / f (8.) |
| Yagi antena | Yagi antenna | Virziena antena ar reflektoru, aktīvo elementu un direktoriem (13.) |
| Zemējums | Grounding | Iekārtu korpusu savienojums ar zemi drošībai (17.) |
| Zemes vilnis | Ground wave | Vilnis, kas izplatās gar Zemes virsmu (14.) |
